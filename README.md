## 🧭 ¿De qué trata este curso?

Este curso es una introducción al mundo de la ciberseguridad. A través de escenarios prácticos ambientados en la empresa ficticia **@Apollo**, se exploran los fundamentos para proteger personas, organizaciones y gobiernos de los ataques digitales.

A lo largo del curso aprenderás a:

- 🔍 Identificar los tipos de amenazas, ataques y vulnerabilidades más comunes.
- 🛡️ Proteger tus datos personales, dispositivos y redes.
- 🏢 Comprender cómo las organizaciones defienden su infraestructura.
- ⚖️ Actuar de manera legal y ética como profesional de ciberseguridad.
- 🎓 Explorar las oportunidades de carrera en el campo.

## 🧠 Conceptos Fundamentales del Curso

### La Tríada CIA
El pilar de toda la seguridad de la información:

| Principio | Descripción |
|---|---|
| 🔒 **Confidencialidad** | Solo los autorizados acceden a la información |
| ✅ **Integridad** | La información no es modificada sin autorización |
| 📡 **Disponibilidad** | La información está accesible cuando se necesita |

### Los 3 Tipos de Atacantes
| Sombrero | Intención |
|---|---|
| ⬜ Blanco | Ético, con permiso, mejora la seguridad |
| 🔲 Gris | Sin permiso, sin intención claramente maliciosa |
| ⬛ Negro | Malicioso, busca beneficio ilegal |

### Malware — Referencia Rápida
| Tipo | Característica clave |
|---|---|
| Virus | Se replica adjuntándose a archivos; requiere acción del usuario |
| Gusano | Se replica solo; no necesita anfitrión ni acción del usuario |
| Troyano | Se disfraza de software legítimo; no se replica |
| Ransomware | Cifra datos y exige rescate |
| Spyware | Espía y roba datos silenciosamente |
| Rootkit | Modifica el SO para crear acceso remoto oculto |
