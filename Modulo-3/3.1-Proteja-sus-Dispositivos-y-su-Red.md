## 📚 Contenido

### 3.1.1 ¿Qué es la seguridad en línea?

> La **seguridad en línea** consiste en tomar las medidas necesarias para evitar que tu información personal caiga en malas manos.

**Pasos básicos al configurar un nuevo dispositivo:**

- Encender el firewall
- Instalar antivirus y antiespía
- Administrar el sistema operativo y el navegador web
- Configurar la protección de contraseñas

---

### 3.1.2 Protegiendo sus Dispositivos Informáticos

| Medida | Descripción |
|---|---|
| 🔥 **Encienda el firewall** | Usar al menos un firewall (software o hardware en el enrutador). Debe estar siempre activo y actualizado |
| 🦠 **Instale antivirus y antiespía** | Analiza el equipo y el correo entrante para detectar y eliminar malware. Solo descargar software de sitios de confianza |
| 🖥️ **Administre el SO y el navegador** | Configurar la seguridad a nivel medio o alto. Instalar parches y actualizaciones periódicamente |
| 🔑 **Configure protección de contraseñas** | Todos los dispositivos deben estar protegidos con contraseña. Cifrar la información almacenada, especialmente datos sensibles |

#### ⚠️ Riesgo especial — Dispositivos IoT

- Reciben actualizaciones de software con **mucha menos frecuencia** que computadoras o móviles.
- Si se descubre una vulnerabilidad, el dispositivo puede **quedarse expuesto indefinidamente**.
- Al comprometerse, permiten a los hackers **acceder a toda la red local**.
- 🛡️ **Solución:** Conectar dispositivos IoT en una **red aislada** separada de la red principal.
- 🔍 Herramienta útil: [Shodan](https://www.shodan.io/) — escáner web para identificar dispositivos IoT vulnerables.

---

### 3.1.3 Seguridad de la Red Inalámbrica en Casa

| Buena práctica | Descripción |
|---|---|
| 📡 **Cambiar el SSID y contraseña predeterminados** | Los hackers conocen los valores de fábrica; deben cambiarse siempre |
| 🔐 **Habilitar cifrado WPA2** | Cifra la comunicación inalámbrica entre el router y los dispositivos |

#### 🔓 Vulnerabilidad KRACK (2017)

- Se descubrió una falla en el protocolo **WPA2** que afecta a **todas las redes Wi-Fi modernas**.
- El ataque **KRACK** *(Key Reinstallation Attack)* rompe el cifrado entre el router y el dispositivo, dando acceso a los datos de la red.

**Mitigación:**

- Actualizar routers, laptops y dispositivos móviles tan pronto como haya parches disponibles.
- Usar **cable** en dispositivos con tarjeta de red cableada.
- Usar una **VPN confiable** al acceder a redes inalámbricas.

> 🔗 Más información: [krackattacks.com](https://www.krackattacks.com/)

---

### 3.1.4 Riesgos del Wi-Fi Público

> Las redes Wi-Fi públicas son convenientes, pero **no deben usarse para acceder o enviar información personal**.

**Recomendaciones:**

- Verificar que el dispositivo **no esté configurado para compartir archivos** o datos multimedia.
- Requerir **autenticación de usuario con cifrado**.
- Usar siempre un servicio de **VPN cifrada** para evitar el espionaje de datos.
- Mantener el **Bluetooth desactivado** cuando no se use — puede ser explotado para espiar, establecer acceso remoto, distribuir malware o agotar la batería.

> 💡 Incluso si un hacker intercepta datos en un **túnel VPN cifrado**, no podrá descifrarlos.

### 3.1.5 Seguridad por Contraseña — Buenas Prácticas

> ❌ **Mala práctica:** Usar la misma contraseña en múltiples cuentas o escribirlas en lugares físicos accesibles.  
> ✅ **Buena práctica:** Usar contraseñas únicas por cuenta y gestinarlas con un administrador de contraseñas.

**Administrador de contraseñas:** herramienta que almacena y cifra todas tus contraseñas y permite el inicio de sesión automático.

---

### 3.1.6 Cómo Crear una Contraseña Segura

| # | Regla |
|---|---|
| 1️⃣ | No use palabras del diccionario ni nombres en ningún idioma |
| 2️⃣ | No use errores ortográficos comunes de palabras del diccionario |
| 3️⃣ | Use caracteres especiales: `! @ # $ % ^ & * ( )` |
| 4️⃣ | No use nombres de equipos o cuentas |
| 5️⃣ | Use contraseñas con **más de 10 caracteres** |

---

### 3.1.7 Frases de Contraseña *(Passphrases)*

Una **frase de contraseña** es más larga que una contraseña típica y adopta la forma de una oración. Es más fácil de recordar y más resistente a ataques de diccionario y fuerza bruta.

**Ejemplo:** `Acat th@tlov3sd0gs.`

**Cómo crear una buena frase de contraseña:**

| Paso | Consejo |
|---|---|
| ❤️ | Elige una declaración que sea **significativa para ti** |
| #️⃣ | Agrega **caracteres especiales**: `! @ # $ % ^ & * ( )` |
| ⏳ | Cuanto más larga, **mejor** |
| 🚫 | Evita declaraciones famosas, como letras de canciones populares |

---

### 3.1.8 Pautas del NIST para Contraseñas

El **Instituto Nacional de Normas y Tecnología (NIST)** de EE.UU. publicó los siguientes requisitos:

| Pauta | Detalle |
|---|---|
| 📏 **Longitud** | Mínimo 8 caracteres, máximo 64 |
| 🚫 **Sin contraseñas comunes** | Evitar: `contraseña`, `abc123`, etc. |
| 🔓 **Sin reglas de composición obligatorias** | No exigir números, mayúsculas y minúsculas de forma forzada |
| 👁️ **Mostrar contraseña al escribir** | Para mejorar la precisión del usuario |
| ✅ **Permitir todos los caracteres** | Incluyendo espacios y caracteres especiales |
| 🚫 **Sin sugerencias de contraseña** | Para evitar pistas que faciliten ataques |
| ♾️ **Sin caducidad de contraseña** | No forzar cambios periódicos |
| 🚫 **Sin autenticación por conocimiento** | No preguntas secretas ni historial de transacciones |

> 🔗 Más información: [NIST SP 800-63-3](https://pages.nist.gov/800-63-3/)

---

### 3.1.9 Evaluación de Contraseñas — ¿Fuerte o Débil?

Para identificar si una contraseña es fuerte, verifica:

- ✅ Tiene más de 10 caracteres
- ✅ Incluye mayúsculas, minúsculas, números y símbolos
- ✅ No es una palabra del diccionario ni un nombre
- ✅ No contiene información personal (fechas, nombres de mascotas, etc.)
- ✅ Es única (no reutilizada en otras cuentas)

## 🧠 Términos clave

| Término | Definición |
|---|---|
| **Firewall** | Sistema que controla el tráfico de red para bloquear accesos no autorizados |
| **Antivirus** | Software que detecta y elimina programas maliciosos |
| **SSID** | Identificador de red inalámbrica (nombre de la red Wi-Fi) |
| **WPA2** | Protocolo de cifrado para redes Wi-Fi |
| **KRACK** | Ataque que explota una vulnerabilidad en WPA2 para romper el cifrado Wi-Fi |
| **VPN** | Red privada virtual que cifra la conexión a Internet |
| **Frase de contraseña** | Contraseña larga con forma de oración, más resistente a ataques |
| **Administrador de contraseñas** | Herramienta que almacena y cifra todas las contraseñas del usuario |
| **NIST** | Instituto Nacional de Normas y Tecnología de EE.UU.; publica estándares de seguridad |
| **IoT** | Internet de las Cosas; dispositivos físicos conectados a Internet |
