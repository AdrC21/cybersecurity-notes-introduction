## 📚 Contenido

### 2.1.1 ¿Qué es el Malware?

> El **malware** (software malicioso) es cualquier código que puede utilizarse para **robar datos, eludir controles de acceso, o causar daño o comprometer un sistema**.

Los ciberdelincuentes utilizan muchos tipos diferentes de malware para llevar a cabo sus actividades. Conocer cada tipo y cómo se propagan es clave para contenerlos y eliminarlos.

---

### 2.1.2 Tipos de Malware

| Tipo | Descripción | Propagación / Particularidad |
|---|---|---|
| 🕵️ **Spyware** | Rastrea y espía la actividad en línea; registra teclas y captura datos confidenciales (ej. datos bancarios) | Se agrupa con software legítimo o troyanos; modifica configuraciones de seguridad |
| 📢 **Adware** | Entrega automáticamente anuncios al usuario, generalmente en el navegador web | Se instala con algunas versiones de software; suele venir acompañado de spyware |
| 🚪 **Puerta trasera** *(Backdoor)* | Obtiene acceso no autorizado al omitir los procedimientos de autenticación normales | Funciona en segundo plano; difícil de detectar; permite comandos remotos |
| 💰 **Ransomware** | Mantiene el sistema o los datos cautivos hasta que se realiza un pago | Cifra datos; se propaga por phishing o vulnerabilidades del sistema |
| 😱 **Scareware** | Usa tácticas de miedo para engañar al usuario y que ejecute un programa malicioso | Ventanas emergentes falsas que alertan sobre un supuesto riesgo en el sistema |
| 🌱 **Rootkit** | Modifica el sistema operativo para crear una puerta trasera de acceso remoto | Escala privilegios; modifica herramientas forenses; casi siempre requiere reinstalación del SO |
| 🧬 **Virus** | Se replica y adjunta a otros archivos ejecutables insertando su propio código | Requiere interacción del usuario; se propaga por USB, discos ópticos, red y correo electrónico |
| 🎭 **Troyano** | Aparenta ser legítimo pero ejecuta operaciones maliciosas ocultas | No se replica; se presenta como imagen, audio o juego; actúa como señuelo |
| 🐛 **Gusano** *(Worm)* | Se replica automáticamente para propagarse de computadora en computadora | No requiere programa anfitrión ni interacción del usuario; se expande muy rápido por la red |

---

#### 🔍 Diferencias clave: Virus vs. Troyano vs. Gusano

| Característica | Virus | Troyano | Gusano |
|---|---|---|---|
| ¿Se replica? | ✅ Sí | ❌ No | ✅ Sí |
| ¿Necesita anfitrión? | ✅ Sí | ✅ Sí (disfrazado) | ❌ No |
| ¿Requiere acción del usuario? | ✅ Sí | ✅ Sí (para instalarlo) | ❌ No |

---

#### 📌 Caso real — Gusano Code Red (2001)

> En 2001, el gusano **Code Red** infectó más de **300.000 servidores en solo 19 horas**, convirtiéndose en uno de los ataques más devastadores de la historia de Internet.

---

### 2.1.3 Síntomas de una Infección por Malware

Independientemente del tipo de malware, estos son los síntomas más frecuentes:

- 🐢 **Aumento en el uso del CPU** — el dispositivo se vuelve más lento
- 🧊 **Congelamiento o bloqueo frecuente** del equipo
- 🌐 **Disminución en la velocidad de navegación** web
- 🔌 **Problemas inexplicables con conexiones de red**
- 🗑️ **Archivos modificados o eliminados** sin acción del usuario
- 👻 **Archivos, programas o iconos desconocidos** en el sistema
- ⚙️ **Procesos o servicios desconocidos** en ejecución
- 🔄 **Programas que se cierran o reconfiguran solos**
- 📧 **Correos electrónicos enviados sin el conocimiento del usuario**

---

### 2.1.4 Identificación Rápida — ¿Cuál malware es?

| Descripción | Tipo de Malware |
|---|---|
| Rastrea la actividad en línea y captura datos personales | 🕵️ Spyware |
| Entrega anuncios automáticamente al usuario | 📢 Adware |
| Mantiene el sistema cautivo hasta recibir un pago | 💰 Ransomware |
| Código que se adjunta a programas legítimos; se propaga por USB o correo | 🧬 Virus |
| Se replica de forma independiente explotando vulnerabilidades de red | 🐛 Gusano |

---

## 🧠 Términos clave

| Término | Definición |
|---|---|
| **Malware** | Software malicioso diseñado para dañar, robar datos o comprometer sistemas |
| **Spyware** | Malware que espía la actividad del usuario y roba información |
| **Ransomware** | Malware que cifra datos y exige un pago para liberarlos |
| **Rootkit** | Malware que modifica el SO para permitir acceso remoto oculto |
| **Backdoor** | Puerta trasera que omite los mecanismos de autenticación normales |
| **Troyano** | Malware disfrazado de software legítimo |
| **Gusano** | Malware autoreplicante que se propaga por la red sin intervención humana |
| **Escalada de privilegios** | Técnica para obtener acceso a recursos normalmente restringidos |
| **Carga útil** *(payload)* | Código malicioso que ejecuta el daño real dentro de un malware |
