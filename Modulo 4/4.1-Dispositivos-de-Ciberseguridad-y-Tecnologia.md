## 📚 Contenido

### 4.1.1 Dispositivos de Seguridad — Las 6 Categorías

> No existe un único dispositivo que resuelva todas las necesidades de seguridad. Se deben combinar múltiples herramientas.

| Dispositivo | Función |
|---|---|
| 🌐 **Routers** | Interconectan segmentos de red y proporcionan filtrado básico de tráfico; definen qué equipos pueden comunicarse entre segmentos |
| 🔥 **Cortafuegos (Firewalls)** | Analizan el tráfico en profundidad e identifican comportamientos maliciosos; aplican políticas de seguridad sofisticadas |
| 🚨 **Sistemas de Prevención de Intrusiones (IPS)** | Usan firmas de tráfico para detectar y bloquear tráfico y ataques maliciosos |
| 🔒 **Redes Privadas Virtuales (VPN)** | Permiten a empleados remotos conectarse mediante un túnel cifrado seguro; también interconectan sucursales con la sede central |
| 🦠 **Antimalware / Antivirus** | Usan firmas o análisis de comportamiento para identificar y bloquear código malicioso |
| ⚙️ **Otros dispositivos** | Seguridad web y de correo, dispositivos de descifrado, servidores de control de acceso, sistemas de gestión de seguridad |

### 4.1.3 Tipos de Cortafuegos (Firewalls)

> Un **firewall** controla y filtra qué comunicaciones se permiten entrar o salir de un dispositivo o red. Puede ser basado en host (protege una computadora) o basado en red (protege toda una red).

| Tipo | Filtra según |
|---|---|
| 🌐 **Capa de red** | Direcciones IP de origen y destino |
| 🔌 **Capa de transporte** | Puertos de datos de origen/destino y estados de conexión |
| 📱 **Capa de aplicación** | Aplicación, programa o servicio específico |
| 🧠 **Capa sensible al contexto** | Usuario, dispositivo, función, tipo de aplicación y perfil de amenaza |
| 🔎 **Servidor proxy** | Solicitudes de contenido web: URL, nombres de dominio, tipos de medios |
| 🔄 **Servidor proxy inverso** | Protege, oculta y distribuye el acceso a servidores web (colocado frente a ellos) |
| 🏷️ **NAT (Traducción de direcciones de red)** | Oculta/enmascara las direcciones privadas de los hosts de la red |
| 💻 **Basado en host** | Puertos y llamadas de servicio del sistema en un solo SO de computadora |

**Casos prácticos de @Apollo:**

| Escenario | Tipo de Firewall |
|---|---|
| Red LAN interna accede a Internet a través de una sola conexión | 🏷️ NAT |
| Windows bloquea por defecto el acceso desde otros equipos de la red | 💻 Basado en host |
| No se permite acceder a URLs de juegos de apuestas desde la red | 🔎 Servidor proxy |

### 4.1.4 Análisis de Puertos

> A cada aplicación en un dispositivo se le asigna un **número de puerto**. El **escaneo de puertos** verifica qué puertos están abiertos en un host de red.

**Usos:**
- 🔴 **Malicioso:** Reconocimiento para identificar el SO y servicios vulnerables.
- 🟢 **Inofensivo:** El administrador verifica las políticas de seguridad de la red.

**Herramienta recomendada:** [Zenmap](https://nmap.org/zenmap/) / [Nmap Online](https://hackertarget.com/nmap-online-port-scanner/)

**Interpretación de resultados:**

| Estado | Significado |
|---|---|
| ✅ **Abierto / Aceptado** | Otros dispositivos de red pueden acceder al puerto/servicio → puede ser explotado si hay vulnerabilidad |
| 🔴 **Cerrado / Denegado / Sin escuchar** | El puerto/servicio no está activo → no puede ser explotado |
| 🛡️ **Filtrado / Eliminado / Bloqueado** | El firewall bloquea el acceso → no puede ser explotado |

> ⚠️ El análisis de puertos debe considerarse un **precursor de un ataque** y nunca debe realizarse en servidores públicos o redes ajenas **sin permiso**.

### 4.1.5 IDS vs. IPS

| Característica | IDS (Detección) | IPS (Prevención) |
|---|---|---|
| **Función** | Detecta, registra y genera alertas | Bloquea o deniega tráfico malicioso activamente |
| **Acción ante amenaza** | Solo reporta — no detiene el ataque | Detiene el ataque en tiempo real |
| **Posición en la red** | Fuera de línea (recibe copia del tráfico via switch) | En línea, dentro del flujo de tráfico |
| **Impacto en red** | Genera latencia si está en línea | Procesamiento en tiempo real |

**Herramienta reconocida:** **Snort** (versión comercial: **Sourcefire de Cisco**) — análisis en tiempo real, escaneo de puertos, comparación de contenido, detección de sondas y ataques.

> 💡 **Ataque de día cero:** Cuando los hackers explotan fallas de software antes de que el fabricante las corrija. El objetivo es detectarlos y detenerlos en tiempo real o en minutos.

---

### 4.1.6 Detección en Tiempo Real

Los ataques modernos a menudo no se detectan hasta días o meses después. La detección en tiempo real requiere:

- Análisis activo con firewalls e IDS/IPS
- Detección de malware de próxima generación conectada a centros de amenazas globales
- Detección de anomalías de red mediante **análisis basado en comportamiento**

> 🚨 **DDoS** es una de las mayores amenazas que requiere respuesta en tiempo real — los ataques provienen de miles de hosts zombies y se disfrazan como tráfico legítimo.

### 4.1.7 Protección contra Malware Avanzado — AMP de Cisco

La solución **AMP (Advanced Malware Protection) Threat Grid** de Cisco:

| Equipo | Beneficio |
|---|---|
| 🏢 **Centro de Operaciones Seguras** | Recopila datos más precisos y procesables |
| 🚒 **Respuesta a Incidentes** | Acceso a información forense para analizar comportamientos sospechosos rápidamente |
| 🔬 **Inteligencia de Amenazas** | Mejora proactiva de la infraestructura de seguridad |
| 🏗️ **Ingeniería de Infraestructura** | Consume y actúa sobre información de amenazas de forma automatizada |

| # | Práctica | Descripción |

| 7️⃣ | **Controles de acceso** | Roles de usuario, niveles de privilegio y autenticación robusta |
| 8️⃣ | **Pruebas de respuesta** | Equipo de respuesta a incidentes con simulacros de emergencia |
| 9️⃣ | **Monitoreo de red** | Solución de monitoreo integrada con otras tecnologías |
| 🔟 | **Dispositivos de seguridad** | Routers, firewalls y dispositivos de próxima generación |

## 🧠 Términos clave

| Término | Definición |
|---|---|
| **IDS** | Sistema de Detección de Intrusiones; detecta y alerta sin bloquear |
| **IPS** | Sistema de Prevención de Intrusiones; detecta y bloquea activamente |
| **Firewall NAT** | Cortafuegos que oculta las direcciones IP privadas de la red interna |
| **Snort / Sourcefire** | Herramienta IDS/IPS reconocida; versión comercial de Cisco |
| **Análisis de puertos** | Proceso de verificar qué puertos están abiertos en un host de red |
| **Latencia** | Retraso en la red causado por el procesamiento del IDS en línea |
| **Ataque de día cero** | Explotación de una vulnerabilidad antes de que el fabricante la corrija |
| **AMP** | Advanced Malware Protection de Cisco; protección avanzada contra malware |
| **APT** | Amenaza Persistente Avanzada; ataque sofisticado y de larga duración |
| **NIST** | Instituto Nacional de Estándares y Tecnología; publica guías de buenas prácticas de seguridad |
