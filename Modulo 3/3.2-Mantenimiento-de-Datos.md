## 📚 Contenido

### 3.2.1 ¿Qué es el Cifrado?

> El **cifrado** (o encriptación) es el proceso de convertir información a un formato que una parte no autorizada **no puede leer**. Solo una persona de confianza con la contraseña o clave secreta puede descifrar los datos.

| ✅ Lo que SÍ hace el cifrado | ❌ Lo que NO hace el cifrado |
|---|---|
| Protege el contenido de los datos ante accesos no autorizados | Evitar que alguien intercepte los datos |
| Hace los datos ilegibles sin la clave correcta | Prevenir ataques de ransomware (que también cifran tus datos para pedir rescate) |

> ⚠️ **Importante:** El cifrado por sí solo no evita que un delincuente intercepte los datos — solo impide que los lea. Algunos atacantes cifran tus propios datos y los retienen como rehenes hasta que pagues un rescate (**ransomware**).

---

### 3.2.2 ¿Cómo se Cifran tus Datos? — EFS en Windows

El **Sistema de Encriptación de Archivos (EFS)** es una característica de Windows que permite cifrar datos. Está vinculado directamente a una cuenta de usuario específica — solo ese usuario podrá acceder a los archivos cifrados.

**Pasos para cifrar con EFS:**

| Paso | Acción |
|---|---|
| 1️⃣ | Selecciona uno o más archivos o carpetas |
| 2️⃣ | Clic derecho sobre los datos → **Propiedades** |
| 3️⃣ | Clic en **Avanzado** |
| 4️⃣ | Activa la casilla **"Cifrar contenido para proteger datos"** |
| 5️⃣ | Las carpetas y archivos cifrados se muestran en **color verde** |

---

### 3.2.3 Realiza un Respaldo de tus Datos

> Un **respaldo** (backup) puede evitar la pérdida de datos irreemplazables como fotos familiares o documentos importantes.

**Requisitos de un buen respaldo:**
- Una **ubicación de almacenamiento adicional**
- Copias realizadas de forma **periódica y automática**

**Opciones de almacenamiento:**

| Opción | Descripción | Ventajas | Consideraciones |
|---|---|---|---|
| 🏠 **Red doméstica / local** | Dispositivo NAS, disco duro externo, USB, CD/DVD, cintas | Control total de los datos | Eres responsable del costo y mantenimiento |
| ☁️ **Nube** | Servicios como Amazon Web Services (AWS) | Seguro ante fallas físicas (incendio, robo); acceso desde cualquier lugar | Costo según espacio; depende del acceso a la cuenta |

---

### 3.2.4 ¿Los Archivos Eliminados Realmente Desaparecen?

> **No.** Cuando mueves un archivo a la papelera de reciclaje y lo eliminas, el archivo solo se vuelve **inaccesible desde el sistema operativo**, pero **no se borra físicamente** del disco.

Cualquier persona con **herramientas forenses adecuadas** puede recuperar el archivo, gracias al **rastro magnético** que deja en el disco duro.

---

### 3.2.5 ¿Cómo Eliminar Datos de Forma Permanente?

Para que los datos sean irrecuperables, deben **sobrescribirse con unos y ceros varias veces** usando herramientas especializadas.

| Método | Sistema operativo | Herramienta |
|---|---|---|
| 🖥️ **Sobrescritura segura** | Windows | **SDelete** (Microsoft, para Vista y versiones posteriores) |
| 🐧 **Sobrescritura segura** | Linux | **Shred** |
| 🍎 **Sobrescritura segura** | Mac OS X | **Secure Empty Trash** |
| 🔨 **Destrucción física** | Cualquiera | Destruir físicamente el disco duro o dispositivo de almacenamiento |

> ⚠️ **La única forma de garantizar al 100% que los datos son irrecuperables es destruir físicamente el dispositivo de almacenamiento.**

> 🌐 **No olvides:** Si tienes copias en la nube, también deben eliminarse desde allí.

## 🧠 Términos clave

| Término | Definición |
|---|---|
| **Cifrado / Encriptación** | Proceso de convertir datos a un formato ilegible para usuarios no autorizados |
| **EFS** | Sistema de Encriptación de Archivos de Windows, vinculado a una cuenta de usuario |
| **Respaldo / Backup** | Copia de seguridad de datos almacenada en una ubicación adicional |
| **NAS** | Dispositivo de almacenamiento conectado a la red doméstica |
| **Ransomware** | Malware que cifra los datos de la víctima y exige un pago para liberarlos |
| **SDelete** | Herramienta de Microsoft para la eliminación segura y permanente de archivos en Windows |
| **Rastro magnético** | Huella que deja un archivo en el disco duro incluso después de ser "eliminado" |
| **Forense digital** | Disciplina que recupera datos de dispositivos de almacenamiento mediante herramientas especializadas |
