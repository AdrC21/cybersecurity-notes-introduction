## 📚 Contenido

### 4.3.1 CSIRT de Cisco

> Un **CSIRT** (Equipo de Respuesta a Incidentes de Seguridad Informática) recibe, revisa y responde a informes de incidentes de seguridad.

**Cisco CSIRT va más allá** con un enfoque **proactivo:**

| Actividad | Descripción |
|---|---|
| 🔍 Evaluación proactiva de amenazas | Identifica riesgos antes de que ocurran incidentes |
| 🛡️ Planificación de mitigación | Prepara planes para reducir el impacto de amenazas |
| 📊 Análisis de tendencias | Estudia patrones de incidentes para anticipar futuros ataques |
| 🏗️ Revisión de arquitectura de seguridad | Evalúa y mejora la estructura de seguridad de la organización |

**Colaboraciones de Cisco CSIRT:**

- **FIRST** — Foro de Equipos de Seguridad y Respuesta a Incidentes
- **NSIE** — Intercambio de Información de Seguridad Nacional
- **DSIE** — Intercambio de Información de Seguridad de Defensa
- **DNS-OARC** — Centro de Análisis e Investigación de Operaciones de DNS

### 4.3.2 Libro de Estrategias de Seguridad *(Security Playbook)*

> Un **libro de estrategias de seguridad** es una colección de consultas e informes repetibles que describen procesos estandarizados para la **detección y respuesta a incidentes**.

**¿Qué debe guiar la organización?**

- 🔎 Identificar el riesgo de ciberseguridad para sistemas, activos, datos y capacidades
- 🛡️ Aplicar salvaguardias y capacitar al personal
- 🚨 Plan de respuesta flexible que minimice el impacto de una violación
- 🔁 Medidas y procesos a activar **después** de una violación

**¿Qué debe incluir el libro de estrategias?**

| Elemento | Descripción |
|---|---|
| 🤖 **Automatización de respuestas** | Identificar y automatizar respuestas a amenazas comunes: malware, actividad sospechosa, intentos de autenticación irregulares |
| 🔄 **Definición de tráfico** | Describir claramente el tráfico entrante y saliente |
| 📊 **Información resumida** | Tendencias, estadísticas y recuentos |
| 📈 **Métricas clave** | Acceso rápido y utilizable a estadísticas clave |
| 🔗 **Correlación de eventos** | Cruzar eventos de todas las fuentes de datos relevantes |

### 4.3.3 Herramientas para Prevención y Detección de Incidentes

| Herramienta | Nombre completo | Función |
|---|---|---|
| 📊 **SIEM** | Security Information and Event Management | Recopila y analiza alertas de seguridad, registros y datos históricos/en tiempo real para detección temprana de ataques |
| 🚫 **DLP** | Data Loss Prevention | Evita que datos confidenciales sean robados o escapen de la red; protege datos en uso, en movimiento y en reposo |

---

### 4.3.4 Cisco ISE, TrustSec y StealthWatch

La solución **Cisco Network Visibility and Segmentation (NVS)** combina tres tecnologías:

| Tecnología | Función |
|---|---|
| 👁️ **StealthWatch** | Usa **aprendizaje automático** para analizar el tráfico de red y detectar amenazas, incluso en tráfico cifrado |
| 🪪 **ISE** *(Identity Services Engine)* | Proporciona visibilidad detallada sobre usuarios y dispositivos; actúa como **administrador central de políticas** |
| 🔒 **TrustSec** | Trabaja con ISE para simplificar el control de acceso; aplica automáticamente **segmentación y cuarentena** de amenazas |

```
StealthWatch → detecta el tráfico malicioso
        ↓
ISE → identifica quién y qué está en la red
        ↓
TrustSec → aplica automáticamente la política de segmentación
        ↓
🛡️ Red protegida en tiempo real
```

> Las tres soluciones juntas brindan **visibilidad, control y automatización** para proteger la red en tiempo real.

---

### 4.3.5 Identificación Rápida — ¿Cuál es cuál?

| Descripción | Herramienta |
|---|---|
| Bloquea o deniega tráfico según regla positiva o coincidencia de firmas | **IPS** |
| Diseñado para evitar que datos confidenciales sean robados o escapen de la red | **DLP** |
| Recopila y analiza alertas de seguridad, registros y datos históricos/en tiempo real | **SIEM** |
| Analiza datos contra una base de reglas/firmas, registra y alerta al administrador — pero NO bloquea | **IDS** |

## 🧠 Términos clave

| Término | Definición |
|---|---|
| **CSIRT** | Equipo de Respuesta a Incidentes de Seguridad Informática |
| **Security Playbook** | Colección de procesos estandarizados para detección y respuesta a incidentes |
| **SIEM** | Sistema que recopila y analiza alertas y registros de seguridad en tiempo real |
| **DLP** | Sistema que evita la fuga o robo de datos confidenciales de la red |
| **ISE** | Cisco Identity Services Engine; administrador central de políticas de acceso |
| **TrustSec** | Tecnología Cisco que aplica segmentación y cuarentena de amenazas automáticamente |
| **StealthWatch** | Herramienta Cisco que analiza tráfico de red con aprendizaje automático |
| **NVS** | Cisco Network Visibility and Segmentation; solución integrada de visibilidad y segmentación |
| **FIRST** | Foro de Equipos de Seguridad y Respuesta a Incidentes; red global de colaboración |
| **CERT** | Computer Emergency Response Team; equipo de respuesta ante emergencias informáticas |
