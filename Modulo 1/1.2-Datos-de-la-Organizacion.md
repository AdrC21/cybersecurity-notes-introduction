## 📚 Contenido

### 1.2.1 Tipos de datos de la organización

Las organizaciones manejan dos grandes categorías de datos:

#### 🗂️ Datos Tradicionales

| Tipo | Descripción |
|---|---|
| **Transaccionales** | Compra, venta, producción, operaciones y decisiones de empleo |
| **Propiedad intelectual** | Patentes, marcas registradas, planes de nuevos productos (secretos comerciales) |
| **Financieros** | Declaraciones de ingresos, balances, flujos de caja |

#### 🌐 Internet de las Cosas (IoT) y Big Data

- **IoT:** Red de objetos físicos (sensores, software, equipos) conectados a Internet que recopilan y comparten datos.
- **Big Data:** Crecimiento exponencial de datos generado por la expansión del IoT y el almacenamiento en la nube/virtualización.

### 1.2.2 El Cubo de McCumber

Modelo creado por **John McCumber en 1991** para evaluar iniciativas de seguridad de la información. Tiene **tres dimensiones**:

#### Dimensión 1 — Principios fundamentales (CIA)

| Principio | Descripción | Métodos |
|---|---|---|
| 🔒 **Confidencialidad** | Evita que información sensible sea revelada a no autorizados | Cifrado, autenticación, control de acceso |
| ✅ **Integridad** | Protege la información contra modificaciones intencionales o accidentales | Funciones hash, sumas de comprobación |
| 📡 **Disponibilidad** | Garantiza acceso a sistemas y datos cuando sea necesario | Mantenimiento, backups, actualizaciones |

#### Dimensión 2 — Estados de la información

| Estado | Descripción |
|---|---|
| ⚙️ **Procesamiento** | Datos en uso durante una operación (datos en proceso) |
| 💾 **Almacenamiento** | Datos en memoria o dispositivos permanentes (datos en reposo) |
| 📶 **Transmisión** | Datos viajando entre sistemas (datos en tránsito) |

#### Dimensión 3 — Medidas de seguridad

| Medida | Descripción |
|---|---|
| 🧠 **Concientización, capacitación y educación** | Informar a los usuarios sobre amenazas y acciones de protección |
| 🖥️ **Tecnología** | Soluciones de software/hardware como firewalls |
| 📋 **Política y procedimiento** | Controles administrativos: planes de respuesta, guías de mejores prácticas |

### 1.2.3 Identificar un correo de Phishing

Un correo de phishing puede detectarse por:

- 📛 **Dominio del remitente escrito incorrectamente** — ej. `service@@polo.com` en lugar de `@apollo.com`
- 🔗 **URL del enlace no apunta al sitio oficial**
- ✍️ **Lenguaje, ortografía y gramática deficientes**
- 🖼️ **Gráficos pixelados o de baja calidad**

> ⚠️ **Importante:** Los atacantes pueden usar tu nombre para parecer legítimos (lo encuentran en Internet). Siempre piensa antes de hacer clic.

### 1.2.4 Casos reales de violaciones de datos

#### 🎮 Razer (agosto 2020)
- Un clúster en la nube **mal configurado** expuso información personal de ~100.000 clientes.
- Razer tardó **más de tres semanas** en proteger la instancia.
- Durante ese tiempo, los ciberdelincuentes tuvieron acceso a datos útiles para ataques de ingeniería social y fraude.

#### 💳 Equifax (septiembre 2017)
- Atacantes explotaron una **vulnerabilidad en software de aplicación web**.
- Se expusieron datos personales confidenciales de **millones de clientes**.
- Equifax creó un nuevo dominio para el sitio de respuesta (en lugar de un subdominio de equifax.com), lo que permitió a los ciberdelincuentes crear sitios no autorizados similares para engañar a los clientes.

#### 📡 Botnet Persirai (2017)
- Apuntó a más de **1.000 modelos de cámaras IP**.
- El malware se descargaba, se ejecutaba, se eliminaba a sí mismo y corría en memoria para **evitar detección**.
- Más de **122.000 cámaras** fueron secuestradas para ataques DDoS.

### 1.2.5 Consecuencias de una Violación de Seguridad

| Consecuencia | Descripción |
|---|---|
| 🏴 **Daño a la reputación** | Pérdida de confianza de clientes y empleados; puede tardar años en recuperarse |
| 🖥️ **Vandalismo** | Publicación de información falsa o modificaciones en el sitio web |
| 💰 **Robo** | Robo de datos personales para fraude financiero o de identidad |
| 📉 **Pérdida de ingresos** | Sitio fuera de línea, multas, mayor inversión en seguridad |
| 🧩 **Propiedad intelectual dañada** | Acceso a secretos comerciales que afecta la competitividad |

## 🧠 Términos clave

| Término | Definición |
|---|---|
| **IoT** | Red de objetos físicos conectados a Internet que recopilan y comparten datos |
| **Big Data** | Grandes volúmenes de datos generados por el crecimiento tecnológico |
| **McCumber Cube** | Modelo de seguridad de tres dimensiones creado en 1991 |
| **CIA** | Confidencialidad, Integridad y Disponibilidad — pilares de la seguridad |
| **Phishing** | Técnica de engaño para obtener información personal haciéndose pasar por entidades legítimas |
| **DDoS** | Ataque de denegación de servicio distribuido que inunda recursos de un sistema objetivo |
| **Botnet** | Red de dispositivos infectados controlados remotamente para llevar a cabo ataques |
| **Ingeniería social** | Manipulación psicológica para obtener información confidencial |
